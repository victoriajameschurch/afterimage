THE SCIENCE

Why we
remember.

Memory isn't a recording of the past. It's something the brain continually reconstructs.

01 / MEMORY ISN'T A RECORDING

Every time you remember something, your brain reconstructs it.

Memories aren't stored like videos waiting to be replayed. When you remember an event, networks across the brain work together to rebuild parts of that experience.

02 / EMOTION CHANGES MEMORY

Some moments stay because they mattered.

Emotional experiences can be remembered more strongly than ordinary ones. Structures including the amygdala and hippocampus help the brain connect emotional significance with memory.

03 / MEMORY CAN CHANGE

Remembering can actually change what you remember.

Each time a memory is recalled, it can become vulnerable to modification before being stored again. This is one reason memories can become different over time.

04 / WHY DO RANDOM MOMENTS STAY?

Sometimes the smallest details become the most vivid.

A smell, a song, a particular light, or the feeling of sitting somewhere can unexpectedly bring back an old experience. Sensory cues can become closely associated with memories and trigger their retrieval later.

Memory is personal. Memory is imperfect. Memory is human.
